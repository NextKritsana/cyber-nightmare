# Cyber Nightmare EP1: แม่โทรมาร้องไห้ขอเงิน คุณจะรอดไหม?

**แนว:** โมชันกราฟิกแบบวาดเส้นเรียบ (flat vector) เล่าด้วยสรรพนาม "คุณ" ปิดด้วยวิธีเอาตัวรอด ทำตามคลิปตัวอย่างเรื่องลิฟต์ค้าง
**ผู้เล่า:** มูน (เลือกแล้ว 2026-11-13)
**คลิปนำร่อง:** ใช้เสียง Kanya ของ Mac แทนไว้ก่อน เพื่อจับจังหวะ พอได้เสียงจริงแล้ว ผมจะจัดจังหวะภาพใหม่ตามเสียงจริง
**ความยาว:** ประมาณ 45-50 วิ (เสียงชั่วคราว 49 วิ)

## เสียงมูน (ElevenLabs v4, เสียงน้องพลอย) ประมาณ 600 ตัวอักษร
เจนเป็นไฟล์เดียว ไม่มีบรรทัดเสียงแม่ (ไฟล์แยกอยู่ด้านล่าง)
```
[whispering, ominous] ถ้าคืนนี้ แม่โทรมาร้องไห้ขอเงิน... คุณจะรอดไหม?
[calm, ominous] ห้าทุ่ม คุณนอนเล่นมือถืออยู่คนเดียว
[tense] แล้วสายจากแม่ก็เข้ามา
[tense] เสียงแม่จริงๆ ค่ะ ร้องไห้ สั่นเครือ
[tense, fast] ตอนนั้น สมองจะสั่งให้คุณ... โอนเลย
[shouting] อย่าเพิ่ง!
[serious] นั่นอาจไม่ใช่แม่ แต่เป็น AI เลียนเสียง จากคลิปเสียงไม่กี่วินาทีในโซเชียล
[calm, firm] ให้วางสาย แล้วโทรกลับเบอร์แม่ที่คุณบันทึกไว้เอง
[relieved] แม่รับสายงัวเงีย... แม่หลับอยู่ที่บ้าน ปลอดภัยดี
[warm] ตั้งคำลับไว้กับครอบครัว ตั้งแต่วันนี้
[ominous, whispering] คืนต่อไป... จะเป็นฝันร้ายเรื่องไหน [playful] กดติดตามมูนไว้นะคะ
```
## เสียงแม่ (ไฟล์แยก) ประมาณ 60 ตัวอักษร
เลือกเสียงผู้หญิงสูงวัยใน Voice Library ของ ElevenLabs (เสียงสำเร็จรูป ไม่ต้องโคลนใคร) ผมจะแทรกให้ต่อจาก "แล้วสายจากแม่ก็เข้ามา" เหมือนตอนแทรกเสียงบั๊ก
```
[crying, panicked] ลูก... แม่โดนรถชน ต้องจ่ายค่ารักษาด่วน โอนมาก่อนนะลูก
```
ถ้าไม่อยากเสียเครดิตเพิ่ม ให้มูนพูดบรรทัดนี้แทนก็ได้ โดยใส่ไว้ต่อจากบรรทัด "แล้วสายจากแม่ก็เข้ามา" ในไฟล์ของมูนเลย

## ข้อเท็จจริงที่ใช้
- มิจฉาชีพใช้ AI โคลนเสียงคนในครอบครัวโทรมาขอเงินด่วน ใช้แค่คลิปเสียงสั้นๆ ที่หาได้ในโซเชียล
  - FTC (สหรัฐฯ) เตือนเรื่อง "family emergency scam" ที่ใช้เสียงโคลน (มี.ค. 2023)
  - McAfee "The Artificial Imposter" (2023) ใช้เสียงแค่ประมาณ 3 วิ ก็โคลนได้
- วิธีกันตามคำแนะนำของ FTC: วางสาย โทรกลับเบอร์ที่รู้จักเอง และตั้งคำลับในครอบครัว
- ในคลิปไม่ใส่ตัวเลขสถิติ เรื่องในคลิปเป็นเหตุการณ์สมมติ
